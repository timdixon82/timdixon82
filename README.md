# Hello, I am Tim

I am a blind nerd and accessibility advocate. I build small browser-based tools and projects, most of them useful, some of them just fun. Everything I build aims to meet the Web Content Accessibility Guidelines (WCAG) 2.2 at AAA conformance.

I work with a small Claude Code agent team that turns my requests into shipped code. The team's setup and standards live in [Claude-Agent-Repo-Template](https://github.com/timdixon82/Claude-Agent-Repo-Template).

## Pinned projects

- [Image-Colour-Contrast-Checker](https://github.com/timdixon82/Image-Colour-Contrast-Checker). Drop images into a browser, check WCAG contrast across the text colours found, and download a PDF or Markdown report.
- [LLBS](https://github.com/timdixon82/LLBS). The Living Well Together Strategy site for the Lincoln and Lindsey Blind Society.
- [Clock-Practice](https://github.com/timdixon82/Clock-Practice). A small browser tool for practising telling the time on an analogue clock.
- [SWOT-Builder](https://github.com/timdixon82/SWOT-Builder). An in-browser SWOT analysis builder with AI coaching that runs entirely on the user's device.
- [Braille-Reference](https://github.com/timdixon82/Braille-Reference). A Unified English Braille Grade 2 reference page.
- [Periodic-Table](https://github.com/timdixon82/Periodic-Table). An interactive periodic table built for accessibility from the ground up.
- [Sophies-Escape](https://github.com/timdixon82/Sophies-Escape). A browser-based escape-room puzzle game.
- [SEWC](https://github.com/timdixon82/SEWC). The leaderboard and world-champion tracker for Sophie's Escape.
- [James-Nerf-Squad](https://github.com/timdixon82/James-Nerf-Squad). A party Nerf game with teams, rounds, and a live scoreboard.
- [Birthday_eCards](https://github.com/timdixon82/Birthday_eCards). A set of accessible, animated birthday ecards.
