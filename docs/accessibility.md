## Project-specific notes

This is a Markdown-only GitHub profile repository. The README.md is rendered directly by GitHub's own pipeline; there is no served HTML surface that Pa11y or axe-core can scan. Automated accessibility checking (Pa11y, axe-core) is therefore not applicable to this repository type.

Accessibility enforcement for the profile page is manual: Tim reviews the rendered output on GitHub and in assistive technology as changes are made.

The accessibility workflow (Pa11y and axe-core at WCAG 2.2 AAA) has not been added to this repository because there is no URL to scan. This inapplicability is a property of the repository type, not an exception. No Pa11y ignore list or exceptions record is needed.
